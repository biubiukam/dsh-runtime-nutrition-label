# ADR 0001：发布证据，而不是单一总分

[English](0001-evidence-not-score.md) | 中文

## 背景

运行时标签组合部署声明、事件观察和配置推导的分类。这些来源具有不同的权威性，即使它们不一致，也不一定表示 instrumentation 失败。

## 决策

插件发布带有有界证据记录的独立 `declared`、`observed` 和 `inferred` 字段，不发布单一安全、信任或风险总分。

## 考虑过的替代方案

- 拒绝单一总分，因为它会隐藏某个值来自配置还是运行时证据。
- 拒绝隐藏的提供方检查 API，因为通用 DSH 事件无法建立稳定的 Cordis 插件拥有者身份。
- 拒绝保留原始 payload，因为调试期间导出的报告必须安全。

## 后果

消费者必须对显式字段定义自己的策略。报告不容易直接排序，但操作员可以解释每个值并保留证据来源。未来的评分可以作为独立消费者实现，而无需改变采集或隐私语义。

## 验证

测试断言来源分离的证据、有界记录、不可变 snapshot、显式归属，以及原始参数、结果、URL 和文件内容不会出现在输出中。
