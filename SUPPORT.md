# Support

English | [中文](SUPPORT.zh.md)

Use GitHub Discussions for usage questions and design proposals. Use GitHub Issues for reproducible bugs and feature requests.

When reporting a problem, include the package version, Node version, DSH runtime version, a sanitized configuration excerpt, the command run, and the smallest relevant snapshot fragment. Do not include credentials, raw arguments, raw results, file contents, or complete URLs.

Before opening a report, run `CI=1 pnpm check` and state which checks passed or failed.
